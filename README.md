# 🏨 User Service - System Integration - BookingHotel

Layanan ini merupakan bagian dari sistem integrasi **BookingHotel** yang berfungsi sebagai **Provider** dan bertanggung jawab untuk mengelola **data customer**.

---

## 📌 Fitur

Layanan ini memiliki **5 endpoint** utama yang berkaitan dengan pengelolaan data pribadi customer, antara lain:

- Menambah data customer
- Melihat detail customer
- Mengubah informasi customer
- Menghapus data customer
- Menampilkan semua data customer
